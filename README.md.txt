# Генерація та проходження лабіринтів

Курсовий проєкт з дисципліни «Об'єктно-орієнтоване програмування»

## Стек технологій та архітектура
* **C++ (`cpp_core`):** реалізація ядра системи, моделей сіток (прямокутна, альтернативна сітка), алгоритмів генерації лабіринтів, алгоритмів пошуку шляху та збору статистики.
* **Python (`python_app`):** графічний інтерфейс користувача, покрокова візуалізація процесів генерації та проходження, режим ручного керування.

## Основний функціонал проєкту
1. **Моделі сіток:** підтримка прямокутної сітки та щонайменше однієї додаткової (напр., гексагональної або кругової).
2. **Алгоритми генерації:** реалізація щонайменше трьох алгоритмів з різною структурою лабіринту.
3. **Алгоритми проходження:** щонайменше три алгоритми пошуку шляху з покроковою візуалізацією.
4. **Статистика та порівняння:** порівняння алгоритмів за довжиною шляху, кількістю відвіданих клітинок, часом виконання та аналізом тупиків/розгалужень.
5. **Інтерактивність:** режим ручного проходження лабіринту користувачем через графічний інтерфейс.

## Використання ООП та паттернів
* **Концепції ООП:** Абстракція, інкапсуляція, наслідування, поліморфізм, дотримання принципів SOLID.
* **Шаблони проєктування:** Реалізація щонайменше 3 паттернів GoF із двох різних груп із детальним обґрунтуванням.
